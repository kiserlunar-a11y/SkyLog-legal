SkyLog · 최종 업데이트: 2026-08-30 · 문의: skylog486@gmail.com

1. 개요

SkyLog(이하 "앱")은 여행·비행 기록 서비스를 제공합니다. 본 방침은 앱 운영자 웨이포인트 코드(Waypoint Code)(이하 "운영자")가 수집·이용·보관·삭제하는 개인정보와 권리에 대해 설명합니다.

2. 수집하는 정보

  • 계정: SkyLog/Firebase 계정 식별자(UID), 로그인 제공자 및 Google 또는 Apple 로그인 시 제공되는 이메일, 표시 이름, 프로필 사진 URL(Firebase Authentication)
  • 비행 기록: 사용자가 입력하거나 자동 조회한 편명, 날짜, 공항, 항공사, 거리 및 관련 정보
  • 여권 프로필 사진(선택): 사용자가 선택한 이미지. 기기에 저장되며 로그인 시 Firebase Storage(클라우드)에 동기화될 수 있음
  • 발자국(선택): GPS를 국가·체류일·도시(수집 시점) 단위로 변환한 방문 기록. 「항상」 위치 허용 시:
    • Android: 앱 사용 중 약 500m 이동 시, 앱 미실행 시 약 2시간마다(정확한 시각 보장 없음) 및 날짜 변경(자정) 시 위치 1회 수집 시도. GPS·네트워크 실패 시 마지막으로 알던 국가로 체류일을 보충할 수 있음
    • iOS: 앱 미실행 포함 약 500m 이상 이동·방문 도착(Visit) 시 수집될 수 있으며, 자정 및 약 08·14·22시경(정확한 시각 보장 없음) 백그라운드 갱신을 시도합니다. GPS·네트워크 실패 시 마지막으로 알던 국가로 체류일을 보충할 수 있음
    • 발자국 탭 「지금 갱신」으로 수동 기록 가능
    • 사용자가 추가한 홈 화면·잠금 화면 위젯은 현재 여행·체류일·쉥겐 90/180 요약을 표시할 수 있음(위젯 자체는 위치를 수집하지 않으며, 표시 내용은 기기 잠금 화면 설정에 따라 주변 사람에게 보일 수 있음)
    • 오프라인: 위치 좌표를 앱의 기기 전용 저장공간에 최대 7일간 임시 보관 후, 앱 실행·네트워크 연결 시 국가·체류일로 변환·반영(7일 초과분 자동 삭제). 원시 좌표는 SkyLog의 Firebase 클라우드에 업로드하지 않음
    체류일의 핵심은 국가별 방문 일수이며, 도시는 수집 시점 기준으로 기록됩니다.
  • Google 지도 타임라인 파일(선택): 사용자가 직접 선택한 원본 JSON 파일은 기기에서 읽으며 SkyLog 서버에 업로드하거나 보관하지 않습니다. 발자국 가져오기 과정에서 국가·도시 확인이 필요한 일부 좌표는 기기 운영체제가 제공하는 Apple 또는 Google의 역지오코딩 서비스에서 처리될 수 있습니다. 로그인한 경우 변환된 국가·도시별 일일 기록과 가져오기 정보(기간, 생성 시각, 활성·되돌림 상태)가 Firebase에 동기화될 수 있습니다. 여행 리와인드는 좌표를 해당 화면의 미리보기와 영상 생성에만 사용하고 발자국이나 클라우드 기록에 추가하지 않습니다.
  • 화면 녹화(여행 리와인드, 선택): 영상을 만들 때 Android MediaProjection 또는 iOS ReplayKit이 화면에 표시된 여행 리와인드 미리보기를 녹화합니다. 마이크 소리는 녹음하지 않고, SkyLog가 백그라운드로 전환되면 녹화를 중단합니다. 완성된 MP4는 앱의 임시 저장공간에 먼저 저장되며, 사진 앱에 저장하거나 다른 앱으로 공유할지는 사용자가 선택합니다.
  • 음성 입력(선택): 기기 OS 또는 OS가 선택한 음성 인식 제공자가 변환한 텍스트. 기기·설정·제공자에 따라 네트워크 음성 인식 서비스가 사용될 수 있으며, 운영자 서버는 음성 원본을 수신하거나 저장하지 않음
  • 앱 설정·활동 정보: 발자국 목표 모드, 배지와 획득일, 연속 기록일, 여행자 등급 산정에 사용하는 최고 활동 점수(XP). 기기에 저장되며 일부는 로그인 시 Cloud Firestore에 동기화될 수 있음
  • 여행 리와인드 생성 혜택 상태: 첫 무료 MP4 생성 사용 여부, 보상형 광고로 받은 영상 생성권, 광고 재고 부족 또는 광고 초기화 실패 시 제공되는 대체 생성의 마지막 성공 시각. SkyLog 로그인 UID별로 기기에만 저장되고 Firebase에 동기화되지 않으며, 계정 삭제 시 해당 UID의 상태도 삭제됨
  • 구독 정보: SkyLog Plus 상품, 플랫폼, 활성 상태, 만료 시각, 스토어 거래·구매 식별자. 결제 카드 정보는 운영자가 수집하지 않으며 App Store 또는 Google Play가 처리함
  • 고객지원 정보: 이메일로 문의할 때 이용자가 제공한 이메일 주소, 문의 내용 및 문제 해결에 필요한 계정 정보
  • 광고(무료 이용 시): SkyLog는 Unity LevelPlay를 광고 중개 플랫폼으로 사용하며, ironSource Ads, Unity Ads 및 연결된 광고 수요 파트너를 통해 광고 적용 화면에 배너 광고를 표시하고 보상형 광고를 제공할 수 있음. 광고 제공자는 광고 제공·측정·빈도 제한·사기 방지 및 보안을 위해 IP 주소나 네트워크 정보에서 추정한 대략적 위치, 앱·광고 상호작용, 진단·성능 정보, 기기·앱 식별자 및 플랫폼·사용자 설정에서 허용하는 광고 식별자(Android AAID 등)를 처리할 수 있음. 실제 처리 범위와 광고의 개인 맞춤 여부는 지역·플랫폼·사용자의 동의·거부 선택 및 실제 광고 제공자에 따라 달라질 수 있음. Google UMP는 규제 적용 지역에서 광고 개인정보 선택을 표시·저장하고 동의 신호를 전달하는 동의 관리 도구로 사용되며 광고를 선택하거나 제공하지 않음. 법적으로 사전 동의가 필요한 경우 사용자의 선택이 광고 요청을 허용할 때만 광고 SDK를 초기화함. iOS에서는 앱 추적 투명성(ATT) 권한을 요청하지 않으므로 광고 SDK에 사용 가능한 IDFA가 제공되지 않음. SkyLog Plus 구독 중에는 배너·보상형 광고를 표시하지 않음. 보상형 광고 시청으로 받는 24시간 숨김 혜택은 배너 광고에만 적용되며, 자동 조회 추가나 여행 리와인드 영상 생성과 같은 다른 보상형 광고 혜택을 면제하지 않음. 필요한 경우 설정 > 지원 > 광고 개인정보 설정에서 선택을 변경할 수 있음

3. 권한 및 이용 목적

  • 위치(포그라운드·백그라운드): 발자국 기능(국가·체류일 기록). Android 백그라운드는 시스템 백그라운드 작업(WorkManager)으로 약 2시간마다·날짜 변경 시 샘플을 시도. iOS 백그라운드는 Significant Location Change·Visit·BGAppRefresh(자정 및 약 08·14·22시경, 시각 보장 없음)로 샘플을 시도
  • 배터리 최적화(Android, 선택): 백그라운드 기록 신뢰성을 위해 배터리 최적화 예외 안내를 제공할 수 있음(사용자가 설정에서 선택)
  • 백그라운드 기록 안내(iOS, 선택): 「항상」 위치·백그라운드 앱 새로고침 설정 안내를 제공할 수 있음(사용자가 설정에서 선택)
  • 마이크·음성 인식: 비행 정보 음성 입력(해당 화면에서만). 기기·설정·제공자에 따라 OS가 네트워크 음성 인식 서비스를 사용할 수 있음
  • 사진·파일(선택): 여행 여권 프로필 사진 선택, 여권·연간 리캡 이미지와 여행 리와인드 영상 저장, 사용자가 선택한 비행 기록 파일 및 Google 지도 타임라인 JSON 읽기, 기록 내보내기. 저장·공유한 파일은 사용자가 선택한 앱 또는 저장 위치에 전달됨
  • 화면 녹화(선택): Android MediaProjection 또는 iOS ReplayKit을 사용한 여행 리와인드 영상 생성. 마이크 소리는 녹음하지 않으며, 앱이 백그라운드로 전환되면 녹화를 중단함
  • 인터넷: 로그인·동기화, 비행 자동 조회, 지도
  • 알림(선택): 「알림 받기」를 켜면 여행 기록 재방문 안내·이맘때 비행 추억·연말 리캡이 자동으로 예약됨. 쉥겐 90/180 알림은 별도로 선택할 수 있으며, 발자국 기록을 기준으로 쉥겐 체류 감지·잔여 10·5·1일·90일 도달 시점을 안내함. 모든 알림은 기기 내 데이터로 기기에서 생성·예약되며(서버 푸시 없음), 일반 알림은 예약 당시 현지 시각 기준 22:00~08:00를 피해 예약함. 야간에 감지된 쉥겐 알림은 08:00 이후로 미뤄지며, 쉥겐 안내는 SkyLog 기록에 따른 추정치로 공식 출입국 기록이나 법률 판단을 대신하지 않음
  • 광고(무료): 광고 적용 화면의 배너 광고·보상형 광고. 지원되는 앱 버전에서 보상형 광고를 끝까지 시청하면 24시간 배너 숨김, 자동 조회 3회 또는 새 여행 리와인드 MP4 1개 생성 혜택을 받을 수 있음. 여행 리와인드는 첫 번째로 성공한 MP4 1개를 광고 없이 만들 수 있고, 그 이후 새 MP4마다 생성권 1회가 필요함. 생성권은 MP4 생성이 성공할 때만 사용되며 생성 실패·취소 시 유지됨. 기존에 완성한 영상의 다시 재생·저장·공유에는 추가 광고가 필요하지 않음. 광고 재고 부족 또는 광고 초기화 실패 시에는 영상 생성 성공을 기준으로 24시간당 1회 대체 생성이 제공됨. SkyLog Plus 구독 중에는 모든 광고가 표시되지 않고 여행 리와인드 MP4를 횟수 제한 없이 생성할 수 있음. 규제 적용 지역의 광고 개인정보 선택은 설정 > 지원 > 광고 개인정보 설정에서 변경 가능

4. 제3자 서비스

5. 保存および同期

フライト記録、国・都市・滞在日数へ変換されたあしあと記録、あしあと目標モード、パスポートプロフィール、一部のアプリ設定およびバッジ・活動情報は、本アプリ専用の端末内領域に保存され、サインイン時にFirebaseへ同期される場合があります。オフラインで取得された元の位置座標は逆ジオコーディングまで端末内にのみ最長7日間保存され、SkyLogのFirebaseへはアップロードされません。端末OSの逆ジオコーディングサービスが座標を国・都市の記録へ変換する場合があり、7日を超えた元の位置座標は自動的に削除されます。利用者が選択したGoogle マップのタイムラインの元ファイルは処理後に本アプリへ保持されず、元のファイルおよび座標はFirebaseへ同期されません。「あしあと」に読み込んだ国・都市の日別記録と読み込み情報（対象期間、作成時刻、有効・取り消し状態）だけが同期される場合があります。トラベルリワインドの座標は、該当画面を開いている間、プレビューと動画作成にのみ一時的に使用し、画面を閉じると選択したデータをメモリから破棄します。キャンセルまたは失敗した未完成の動画は削除します。完成した動画の一時ファイルは、画面を閉じるか新しい動画を作成すると削除します。本アプリが予期せず終了した場合、一時動画が端末の一時領域に残ることがあり、OSの方針に従って削除されるか、次に動画を作成するときに24時間を経過したファイルが削除されます。完成した動画を写真アプリへ保存するか、または他のアプリへ共有するかは利用者が明示的に選択します。動画には選択した期間の移動経路が表示される場合があります。トラベルリワインドの初回無料作成の利用状況、動画作成権、および代替作成の直近成功時刻は、SkyLogのサインインUIDごとに端末内のみに保存され、Firebaseには同期されません。アカウント削除時に該当UIDの状態も削除されます。未同期の変更を保護し安全にアカウントを切り替えるため、サインアウト後もアカウント別のローカルコピーが本アプリ専用領域に残る場合があります。データの初期化、アカウントの削除または本アプリのアンインストールにより削除できます。保存・共有したファイルには、利用者が選択した保存先・共有先のポリシーが適用されます。
